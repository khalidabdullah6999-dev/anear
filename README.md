# anear

Website PT. Segi Tiga Tambora.

Situs statis tanpa build: `index.html`, `style.css`, `main.js`. Buka `index.html` langsung di browser untuk melihatnya.

- Teks Bahasa Indonesia ada di `index.html`; terjemahan Inggris ada di objek `EN` di `main.js` (kunci sama dengan atribut `data-i18n`).
- Bagian Proyek masih berisi kartu **Contoh**. Ganti dengan proyek nyata sebelum website diumumkan.

## Tayang di GitHub Pages

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)` → Save.
2. Situs tayang di https://khalidabdullah6999-dev.github.io/anear/ dalam beberapa menit.
3. Domain sendiri (opsional): isi kolom **Custom domain** di halaman yang sama, lalu atur DNS di penyedia domain (lihat petunjuk GitHub Pages untuk custom domain).
